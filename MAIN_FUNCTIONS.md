# 📋 Main Functions of LinguaNews App

## Core Functions List

1. **User Authentication**
   - Sign up with email/password
   - Sign in with email/password
   - Sign in with Google OAuth
   - Sign out

2. **Browse News Articles**
   - View news by category (General, Technology, Business, Science, Health, Sports, Entertainment)
   - Select target language
   - View article cards with images

3. **Read Articles**
   - View full article content
   - Switch between original and translated text
   - Read article in target language

4. **Translate Articles**
   - Translate entire articles to target language
   - View translations side-by-side

5. **Extract Vocabulary**
   - AI extracts important words from articles
   - Shows word with context sentences
   - Shows translations

6. **Save Vocabulary**
   - Save individual words to flashcards
   - Save all vocabulary at once
   - Words stored in Supabase database

7. **Review Flashcards**
   - View all saved vocabulary
   - Filter by language
   - Review with spaced repetition
   - Mark words as correct/wrong
   - Track mastery status

8. **Progress Tracking**
   - View learning statistics
   - See vocabulary mastery
   - Track articles read
   - View streak days

9. **Lyrics Learning** (Premium)
   - Connect Spotify
   - View currently playing song
   - Get song lyrics
   - Extract vocabulary from lyrics

10. **AI Chat** (Premium)
    - Ask questions about articles
    - Get AI-powered explanations
    - Interactive learning

11. **Settings & Profile**
    - Change target language
    - View profile information
    - Manage preferences
